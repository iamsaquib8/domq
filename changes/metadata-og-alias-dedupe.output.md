Metadata: a `<meta>` tag that carries both `property` and `name` for the same `og:` or `twitter:` key (`<meta property="og:title" name="og:title" content="…">`, which many CMS and SEO plugins emit) adds one entry to `Metadata::og` or `Metadata::twitter`, not two ([#36](https://github.com/iamsaquib8/domq/issues/36)). Separate tags that repeat a key, such as several `og:image` tags, are all kept. Anything that counts or iterates those lists sees fewer entries on such pages.
