`NodeRef::attr` and `has_attr` match attribute names ASCII case-insensitively, as `set_attr`, `remove_attr` and selectors already did, so `a.attr("HREF")` finds `href`. This also applies to every caller that passes a name: the CLI's `-a`, `#[domq(attr = "...")]` in the derive, and `Element.attr` in Python. Only ASCII letters fold. Output is unchanged for existing code: domq already stored every name lower-cased ([#74](https://github.com/iamsaquib8/domq/issues/74)).
